Short description about my project
  I have created a working landing page based on the provided layout on Figma 'BANG & OLUFSEN'. My page contains header, aside, main with sections and footer. Header has its own logo, title and allows to call and open a menu. I added hover-effect to icons to show that they are in working condition. When someone clicks on the menu icon, it slides out smoothly. Also I have the ability to smoothly move to the desired section through the menu. My page is adapted for a phone, tablet and computer.
The technologies that were used: HTML - semantic page markup, SCSS - variables, mixins, external styles. I also used grid, positioning if elements, fonts of google font etc. GitHub Pages - platform for deploy preview; Figma - design mockup: - [B&O](https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6817-212&t=ZTV6Gl8NzaWkJ4FK-0)
